# ADAM17_glioma_cell_cycle

## Overview

This repository contains the computational scripts supporting the bulk and single-cell transcriptomic analyses presented in the study. The analyses investigate ADAM17-associated molecular features, cell-cycle regulation, prognostic stratification, signaling states, and predicted drug sensitivity in glioma.

## Analyses

The repository includes code for:

* Cell-cycle activity scoring and gene-program analysis
* Elastic Net regression and stability selection
* Weighted gene co-expression network analysis (WGCNA)
* ADAM17-associated survival analysis
* Single-cell RNA-seq analysis and glioma-cell subclustering
* Cell–cell communication analysis using CellChat
* Multivariable Cox regression
* Pharmacogenomic drug-sensitivity prediction
